Daily Photo Diary App – UI/UX & Product Concept

This project is a UI/UX concept for a daily photo diary application designed to help users document everyday moments through photos, mood tags, and a memory timeline.

Key Features:
- Daily photo entries
- Mood tagging for emotional tracking
- Timeline view for browsing memories
- Clean and minimal interface focused on personal storytelling

Notes:
This project is a design and frontend concept created using Figma AI. It does not include production-ready backend or cloud storage. The goal of this project is to showcase product thinking, UI design, and interaction flow.
